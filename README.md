# THOMAS | Personal Website

**Live demo: [thomasou.com](https://thomasou.com)**

A minimal personal website built with HTML, CSS, and vanilla JavaScript.

## Quick Start

```bash
python3 -m http.server 4317
```

Open http://localhost:4317.

## What It Does

- Interactive Lorenz attractor with rotation, parameter controls, and reduced-motion support

## Tech Stack

| Layer | Tools |
|---|---|
| UI | HTML, CSS, self-hosted Newsreader fonts |
| Visualizations | JavaScript, Canvas 2D |
| Hosting | Vercel |
